# Equipment icons

Line icons from two MIT-licensed sets, tinted at render time to match the app
theme.

**Tabler Icons** — MIT — https://tabler.io/icons
- barbell.svg (tabler:barbell)
- dumbbell.svg (tabler:dumbbell)

**Hugeicons (free set)** — MIT — https://hugeicons.com
- kettlebell.svg (hugeicons:kettlebell)
- machine.svg (hugeicons:equipment-gym-01)
- cable.svg (hugeicons:pulley)
- plate.svg (hugeicons:plate)
- band.svg (hugeicons:skipping-rope)
- bodyweight.svg (hugeicons:workout-squats)
- other.svg (hugeicons:more-horizontal)

Fetched via the Iconify API (https://api.iconify.design). SVGs use
`currentColor` and are tinted via `flutter_svg` `ColorFilter`.
