# Animated icons (Lottie JSON)

Drop Lottie `.json` files from Flaticon's "Weight animated icons" pack by
**Magnific** (https://www.flaticon.com/free-animated-icons/weight) in here.
Download format: **Lottie JSON** (not GIF). Free license requires the
attribution shown in Settings → Support → Icon credits.

Filenames the app looks for (any that are missing simply fall back to the
built-in static icons, so partial sets are fine):

- `dumbbell.json` — workout hero card + empty-workout anchor (default routine icon)
- `push.json` — routine cards whose name contains "push"
- `pull.json` — routine cards whose name contains "pull"
- `legs.json`  — routine cards whose name contains "leg" / "lower" / "squat"
