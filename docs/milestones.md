## Milestone 6: Platform Management Portal (Super-Admin Web) 🖥️
Model: **Platform → Super-Admin (web portal) → Gyms → Owners/Trainers → Members**. Super-admin runs the platform from a web cockpit ("**FitYaar Management**"); gym owners/trainers/members keep doing everything **inside the Flutter app** (backend gates by role). Kept deliberately **low-cost / low-maintenance**: zero build step (vanilla HTML/CSS/JS like `superadmin.html`), served as **Spring static resources** at `/admin/` (same origin → no CORS, one deploy), and **read-mostly** endpoints that compute on the fly (no rollup jobs). Full plan: `~/.claude/plans/cozy-leaping-adleman.md`.

## Milestone 7: Public Website & Web Platform (FitYaar.com) 🌐

One `User`, one auth (`/api/auth`); `user.role` drives destination. The website is a free acquisition engine (Google → tool/exercise → account → app). A public/anonymous read tier is a **new backend concern** (rate-limited, cacheable `/api/public/**`) introduced in Phase B.
