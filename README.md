# FitYaar - India-First Fitness Tracker

FitYaar is a lightweight workout and nutrition tracking app designed specifically for the Indian fitness community.

## 🌟 Vision
Build a fast, simple, and India-first workout and nutrition tracking app inspired by Hevy.

## 📁 Project Structure
- `FitYaar-Backend`: Spring Boot API.
- `FitYaar-Mobile`: Flutter Mobile App.
- `FitYaar-Web`: React Analytics Dashboard.
- `docs`: Documentation.
- `database`: SQL migrations and seed data.
- `storage`: Media and export storage.
